Vice Coast Cover Studio turns your own photos into GTA-style multi-panel poster key art — bold striped-chrome lettering, Vice City sunset and neon grades, face-aware crops, role tags, review strip, seal and billing block — and exports PNGs in 1080×1080, 1080×1350 and 1920×1080, fully offline.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
